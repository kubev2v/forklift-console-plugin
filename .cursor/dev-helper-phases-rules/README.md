# dev-helper phase rules (Forklift)

The [dev-helper](https://github.com/avivtur/dev-helper) skill is installed under
`.cursor/skills/dev-helper/` (gitignored). Files here are **versioned copies**
of project-specific `phases-rules` for dev-helper.

After installing or updating dev-helper:

```bash
mkdir -p .cursor/skills/dev-helper/phases-rules
cp .cursor/dev-helper-phases-rules/*.md .cursor/skills/dev-helper/phases-rules/
```
