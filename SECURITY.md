# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it
responsibly through one of the following channels:

- **Red Hat Product Security:** https://access.redhat.com/security/team/contact
- **Email:** secalert@redhat.com (PGP key: https://access.redhat.com/security/team/key/)

Please **do not** open a public GitHub issue for security vulnerabilities.

## Supported Versions

Security fixes are applied to the latest release branch and any currently
supported downstream product releases (Migration Toolkit for Virtualization).

## Disclosure Policy

Red Hat follows a coordinated vulnerability disclosure process. Once a fix is
available, advisories are published through:

- https://access.redhat.com/security/security-updates/
- https://access.redhat.com/errata/
